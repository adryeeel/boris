# Boris

Boris contains a reusable project foundation in [template/](template/README.md), including its agent guidance, GitHub workflows and license.

To start a project, copy the contents of `template/`, including hidden files, into a new directory and initialize a Git repository there. An agent or contributor can then follow the [setup checklist](docs/setup.md). The [template contents guide](docs/contents.md) explains what is included, and [template values](docs/placeholders.md) distinguishes project placeholders from configuration interfaces.

To work on the template in this repository, run commands from `template/`. The template’s workflow is used by projects created from the folder.
