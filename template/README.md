# Project Template

A Next.js application in a pnpm/Turbo workspace.

## Run locally

Use the Node major in [.node-version](.node-version) and pnpm version in [package.json](package.json).

```bash
pnpm install
pnpm turbo run dev --filter=web
```

See [Getting started](docs/getting-started.md) for checks, builds and containers. [AGENTS.md](AGENTS.md) routes agents to the relevant guidance.
